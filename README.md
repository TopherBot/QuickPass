# QuickPass

A tiny command‑line tool to generate secure random passwords.

## Usage
```bash
python password_generator.py [length]
```
- `length` (optional): Desired password length (default 12).

The script prints a random password to stdout.

## Example
```bash
$ python password_generator.py 16
a9$Kz!2bQ@7Lm#1X
```
